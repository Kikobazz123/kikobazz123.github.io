Privacy policy

Last updated: 5 November 2026

Who we are

Agenttube is operated by LordGen Limited for its own YouTube channels.

What we access

When the channel owner signs in with Google, Agenttube receives permission to upload videos, set their details and thumbnails, schedule publication, and read the channel's video list and analytics. It uses these permissions only to publish and measure LordGen's own videos.

What we store

An OAuth access and refresh token, kept in LordGen's private configuration and its private GitHub repository secrets. We store no other Google user data, and we do not access any account other than the one that signs in.

Sharing

We do not sell, rent or share Google user data with anyone. Data is sent only to Google's YouTube APIs to carry out the actions above.

Google API Services User Data Policy

Agenttube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke Agenttube's access at any time at myaccount.google.com/permissions. We then delete the stored tokens.
